# 漢字練習 — Kanji Practice (iPad Safari)

Single-page, no-build web app for practising kanji with Apple Pencil. It has three drill levels (guided, faint, memory), word boxes, and spaced review.

## Structure
```
index.html            app: CSS (palette in :root) + one script organised in labelled sections:
                      CONFIG · STORAGE · UTILITIES · STROKE CHECKING · DATA ACCESS · STATE ·
                      RENDERING · LEVELS/FLOW · ANIMATIONS · INPUT/PEN · SET PICKER · SERVICE WORKER+INIT
data.js               generated data (window.KANJI_DATA) — do not hand-edit
sw.js                 offline cache (cache-first)
manifest.webmanifest, icons/   home-screen install
tools/                data generator + Playwright tests
deploy/               exact copy for GitHub Pages (static hosting)
screens/              screenshots
```
The data flow is described in the header comment at the top of the script in index.html.

## Run locally
`python3 -m http.server 8000` → open http://localhost:8000/ (the service worker only registers over http(s); opening the file directly also works).

## Editing CONFIG
Every tunable setting is in `CONFIG` at the top of the script, and each one has a comment:
- tolerances (`CHECK.strict` / `CHECK.memory` / `CHECK.ADAPT`)
- `MISSES_FOR_HINT`
- practice flow (`FLOW`: part boxes + stages c–h) and word-box reps (`WORD`)
- ink colour (`INK`) and mastery tiers (`MASTERY`)
- `SCHEDULE_DAYS`
- word audio (`SPEAK_WORD`, `SPEAK_RATE`)
- timings (`FLASH_MS`, `SLIDE_*`, `WORD_BREAK_MS`, `COMBINE`)

To check your changes, run `tools/test_regression.py`, `tools/test_accuracy.py`, `tools/test_label_placement.py` and `tools/test_tts.py`.

## How data.js is generated
No reading or meaning is typed by hand. Everything comes from the sources below.
1. Put the sources in `tools/src/` (or set `KANJI_SRC`):
   - `kanjidic2-en-3.6.2.json` and `jmdict-eng-common-3.6.2.json` from jmdict-simplified 3.6.2+20261012204142
   - `kvgsrc/kanjivg-70a0b7ae/` (KanjiVG at commit 70a0b7ae)
   - `n5.csv` (old JLPT 4 list)
2. `python3 tools/fetch_jisho.py`: caches Jisho pages. They are only used for the KangXi radical number, which names the parts.
3. `python3 tools/words_lookup.py`: resolves the lessons in `tools/lessons.py` against JMdict and writes `work/lessons.json`.
4. `python3 tools/gen_data.py build`: writes `data.js`.

Re-running the steps with the pinned sources reproduces the current data.js byte for byte.

## Service worker version rule
**Whenever any cached file changes (index.html, data.js, icons, manifest), bump `VERSION` in sw.js** (for example kanji-v4 → kanji-v5). If you don't, iPads keep serving the old cached copy. Then copy the app files to deploy/.

## v13 — components-first learning, kana, review queue
- **Files:**
  - `links.js`: app-authored memory links and fallback component keywords. These are original text, not Heisig's.
  - `kana.js`: generated by `tools/gen_kana.py` from KanjiVG.
  - `levels.js`: the list of lazy-loaded N4–N1 files. See `/workspace/kanji-data/SCHEMA.md`.
- **Tabs:** あ / ア (kana rows incl. dakuten and small kana) · 部首 (every kanji ordered so its kanji-components come first, 5 per lesson) · N5… A tab is hidden when it has no data.
- **Flow per kanji:**
  - First time: the full flow. Each new component is shown alone with its keyword. Then: combine, step, trace, freehand. The memory link is shown under the equation while you are not writing from memory.
  - Components you already know skip their part-alone boxes.
  - After 1 clean practice: recall box (blank, from meaning/reading), then a trace with part boxes, then freehand.
  - After 2 clean practices in a row: recall box only.
  - Using any hint resets this streak.
- **復習:** the button in the level bar shows how many words are due. It opens up to 12 due words from all lessons, shuffled.
- **JLPT labels:** new N-levels (`tools/jlpt_new.py`).
- **Tests:**
  - `tools/test_v13.py` (new features)
  - `tools/test_level_files.py` (per-level file validator)
- Research behind the changes: `RESEARCH.md`.

## v14
- **Shape gate** (`CONFIG.CHECK.SHAPE`, `shapeGate()`): after the lenient position check, every stroke must also match the reference stroke on:
  - path length within 0.5–2× (after the placement fit)
  - start→end direction within ±30°
  - end-hook angle within 80° (measured on raw points, so hooks are judged before smoothing)
  - total turning within 120°
  - bow within max(0.2×chord, 0.15 box)

  Dots and short ticks (path length under 0.12 box) skip the gate.
- **Veil:** every box except the current one is blurred (8px), faded and inert, so finished ink never hints the recall.
- **Lesson-complete card:** 次へ (next lesson) / 繰り返す (repeat) / 復習 (when due).
- **Lazy memory links:** links-N4.js and links-N3.js load with their level and are cached by the service worker.
- **New tests:**
  - `tools/test_v14.py`
  - `tools/test_sw_upgrade.py` (old → new SW on one profile)
  - `tools/test_all_lessons.py`
  - `test_accuracy.py` now covers wrong-shape cases: curve+rotate, rotate 50°, another stroke's shape at the right place, and Alexander's 上 screenshot.
